proprietary asset. References to Pixel8r in documentation identify the
historical workflow that informed this reconstruction only. PixelatorPlus is
not affiliated with, sponsored by, or endorsed by Action Dawg, Victoria

palette formats identify compatibility targets only and do not imply affiliation
or endorsement. No third-party palette download is bundled with the extension.

Built-in palette color definitions are rebuilt from public sources as noted in
`core/palettes.py`:

- Hardware palettes (Amiga, Apple II, Atari 2600, C64, NES, Game Boy, Master
  System, ZX Spectrum, Amstrad CPC, MSX, VIC-20, CGA, BBC Micro, SNES, Genesis,
  Apple IIGS, web-safe cube) are reconstructed from publicly documented
  hardware color definitions; see the module docstring for per-palette sources.
- PICO-8 palette: Lexaloffle's PICO-8 fantasy console color set, via Lospec
  (https://lospec.com/palette-list/pico-8). PICO-8 is a trademark of Lexaloffle
  Games; no affiliation or endorsement is implied.
- TIC-80 palette: the TIC-80 fantasy console's default palette, which is
  Sweetie 16 (see below), per Lospec (https://lospec.com/palette-list/tic-80)
  and the TIC-80 source (https://github.com/nesbox/TIC-80, MIT License).
- Sweetie 16 palette by GrafxKid, free to use
  (https://lospec.com/palette-list/sweetie-16).
- DawnBringer 32 palette by DawnBringer, free for any use
  (https://lospec.com/palette-list/dawnbringer-32).
- Resurrect 64 palette by Kerrie Lake, free to use / CC0
  (https://lospec.com/palette-list/resurrect-64).
- Endesga 32 and Endesga 16 palettes by Endesga, free to use
  (https://lospec.com/palette-list/endesga-32,
