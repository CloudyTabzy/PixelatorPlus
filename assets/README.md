# Pixel8r assets

`open_retro_32_palette.png` is a 32-color, 1×32 palette image suitable for
the **Custom Palette** input.

`open_retro_32_lut.png` is the corresponding 4096×4096 RGB image LUT suitable
for the **Custom LUT** input. It uses Pixel8r's documented 16×16 tile layout:
blue selects the tile, red selects X, and green selects Y.

The `luts/` subdirectory contains generated 4096×4096 presets for all of the
native built-in palette modes, including the Game Boy Color 5-bit reducer.
The identity LUT is generated on demand by **Output the Default LUT**.

Both files are generated by `tools/generate_open_retro_lut.py` and are
released under CC0. The blue-noise files are generated by
`tools/generate_blue_noise.py` and have the same asset license.

For third-party palettes, verify the individual creator's license before
bundling. Lospec provides palette data and downloads, but its API page does
not itself grant a blanket redistribution license; use it as a user-import
source unless a palette's creator provides explicit permission.
