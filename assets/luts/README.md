# Built-in image LUT presets

This directory contains generated 4096×4096 PNG image LUTs for the built-in
Pixel8r palette/reducer modes:

`amiga`, `apple2_lores`, `apple2_hires`, `atari2600`, `c64`,
`nes`, `gameboy`, `gameboy_color`, `master_system`, `web`, and `snes`.

They are generated by `tools/generate_builtin_luts.py` from the same
procedural/public palette definitions used by the native NumPy pipeline. They
are not copied from the paid Pixel8r Substance preset. The generated files
are CC0 under `pixelatorplus/assets/ASSET_LICENSE.txt`.

To use one manually, select **Quantization → Lookup Table → Custom LUT** and
load the desired PNG. The add-on's built-in mode already performs the same
mapping without loading the image file. The identity LUT is not bundled:
enable **Output the Default LUT** to generate it inside Blender.
